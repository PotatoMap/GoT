浏览器中保存什么

GoT 不要求注册账号，也没有 GoT 云数据库。棋局恢复点、设置、学习进度、死活题进度、课堂记录和老师 API 配置保存在当前网站地址的浏览器本地存储中，不会由 GoT 自动同步到其他设备。普通棋谱可由你导入、导出。

API Key 保存在当前标签页的会话存储中；浏览器不支持会话存储时，仅在当前页面内存中保留。关闭标签页后需要重新填写。为降低长期暴露风险，旧版本保存在本地存储中的密钥会在升级后迁移到当前标签页，并从长期存储中移除。任何同源页面脚本在标签页打开期间仍可能访问会话密钥，请只在可信的 GoT 网站使用。

使用 AI 老师时会发生什么

读取模型、验证连接或提问时，请求会经 GoT 老师接口发送到你选择的模型服务商。请求可能包含 API Key、模型名称、当前棋盘局面、问题、必要的课堂上下文、对话消息和相关工具结果；老师接口在转发时会接触这些内容。

你也可以填写自定义 OpenAI 兼容服务地址。该地址、API Key 和老师请求会由 GoT 老师接口转发至你指定的服务；该服务会按自己的政策处理收到的数据。请只填写你信任的公开 HTTPS 服务地址。

GoT 接口代码不把请求正文写入数据库，也不记录密钥或提示词；失败诊断只记录服务商、错误类别和受限错误码。Cloudflare 部署可用 API Key 的 SHA-256 摘要作请求限流标识。托管平台可能处理提供服务所需的网络元数据；GoT 无法确认平台账户级日志的字段和保留期限。模型服务商收到的数据按其政策处理，请在使用前查看其说明。

不使用在线老师时，普通对弈和浏览器内置分析在本机浏览器运行；本机版 KataGo 连接你设备上的本地服务。AI 老师需要联网、老师接口和模型服务可用。老师请求不会由 Service Worker 缓存。

查看和删除资料

  • 删除课堂记录：在老师面板的课堂记录中选择“清除课堂记录”。
  • 删除 API Key：进入“设置 → 引擎 → 老师 AI API”，删除对应服务商的密钥。
  • 删除棋局、设置和学习资料：在浏览器的网站数据设置中清除此网站的站点存储；这通常也会清除会话密钥。也可在老师设置中删除密钥，或关闭对应标签页。
  • “清空缓存并重载”只清除应用离线缓存，不会删除上述本地资料。

GoT 无法访问或控制托管平台及模型服务商的日志、备份与数据保留设置。若要了解这些内容，请查看对应服务商的隐私说明。更多使用约定见 使用条款。
