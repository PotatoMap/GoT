GoT 围棋

GoT v1.0.0

GoT 是开源围棋工作台，提供对弈、学习、死活题、棋谱与复盘。

首次公开发布

现代化界面与沉浸式 2D/3D 棋盘，支持 KataGo 智能分析、AI 交互教学、棋谱树浏览和个性化棋具选择。

网站版算力说明
网站版受浏览器和设备算力限制。需要更强的棋力与分析能力，可安装本机版并启用本地 KataGo。

将清除此浏览器保存的 GoT 页面缓存并重新载入。棋局记录和设置不会被清除。

欢迎来到 GoT

在这里开始对弈、浏览棋谱，或按自己的节奏学习围棋。无需安装即可先体验内置棋力；浏览器 KataGo 会在首次使用时自动加载。AI 老师需网站老师接口可用，并使用你自己的模型 API 密钥；密钥仅在当前浏览器保存。

Play a game, explore records, or learn at your own pace. Built-in play is ready right away; browser KataGo loads automatically when first used. The AI teacher requires the site teacher gateway and your own model API key, saved only in this browser.
