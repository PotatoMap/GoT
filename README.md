# GoT GUI · v1.0.0

GitHub Pages 静态发布文件。对应内部开发版 `a2.7.8`。

上传本目录全部内容到 GitHub 仓库根目录，然后在仓库 **Settings → Pages** 中选择从 `main` 分支根目录发布。

此目录只保留网站运行文件，不含 Node 开发环境或 Cloudflare Worker 配置。AI 老师需使用浏览器可访问的兼容服务。
